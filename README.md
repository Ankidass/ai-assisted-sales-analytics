# AI-Assisted Sales Analytics Project (Practice)

**Tools:** Python, pandas, SQL (SQLite), CSV, optional AI-assisted insight drafting  
**Project type:** Portfolio practice using synthetic retail transaction data.

## Important
All records are **synthetic demonstration data**, not real company data. Estimated costs and profits are generated for practice, not verified business accounting. Do not describe this as paid client work or claim business impact.

## Objective
Analyze sales by product category and month, validate data quality, calculate revenue and estimated profit metrics, and use a structured AI prompt to draft hypotheses for further investigation.

## Project structure
- `data/sales_data.csv` — 500 synthetic order rows
- `python/analyze_sales.py` — validation, summaries, and SQLite database creation
- `sql/sales_analysis.sql` — SQL examples for KPIs, category performance, monthly trends, and product review
- `prompts/insight_prompt_template.md` — evidence-first prompt and validation checklist
- `outputs/category_summary.csv` — category-level summary
- `outputs/monthly_summary.csv` — monthly summary
- `sales_demo.sqlite` — generated by running the Python script

## Run it
```bash
pip install pandas
python python/analyze_sales.py
```
The script writes summary CSV files and creates `sales_demo.sqlite` with a table named `sales_data`.

## Questions to investigate
1. Which categories contribute the most revenue?
2. Which categories have the highest estimated profit margin?
3. How does monthly revenue change over time?
4. Which products merit further review when considering revenue, units, discounts, and estimated margin together?

## AI-assisted workflow
1. Run Python/SQL analysis.
2. Copy a summary table into `prompts/insight_prompt_template.md`'s prompt.
3. Ask an AI tool for patterns and hypotheses.
4. Verify every number against the summary and rewrite unsupported explanations.
5. Save only validated findings in your final report.
